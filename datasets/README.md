# Dataset

`alerts.jsonl` is generated by `build_alerts.py`; edit the builder, then run
`python datasets/build_alerts.py`. A test fails if the two disagree.

Each line:

| Field | Meaning |
|---|---|
| `id` | Short name, prefixed by the tool that raised it (`ns` NetScan's Suricata rules, `ltd` Log Threat Detector, `eta` Email Threat Analyzer) |
| `label` | `true_positive` (a real attack) or `false_positive` (approved or harmless activity) |
| `why` | Why the label is right, in one sentence |
| `attacker_fields` | Dotted paths to the fields whoever caused the event controls; the injection suite plants payloads there |
| `alert` | The alert as SOAR-Lite stores it; `alert.context` is what the SOC knows from its own records (trusted) |

Addresses come from documentation ranges (192.0.2.0/24, 198.51.100.0/24,
203.0.113.0/24) or private networks; domains are made up, except well-known
services in the benign emails.
